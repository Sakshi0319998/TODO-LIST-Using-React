# iTask - Todo List App 📝

A simple and elegant **Todo List App** built using **React**, **Vite**, and **Tailwind CSS**. This app allows users to add, edit, delete, and mark todos as completed, with all data stored in **local storage** for persistence.

---

## 🚀 Features

- ✅ Add new todos
- ✏️ Edit existing todos
- ❌ Delete todos
- 📌 Mark todos as completed
- 👁️ Toggle visibility of completed todos
- 💾 Stores todos in browser localStorage
- ⚡ Fast and lightweight with Vite
- 🎨 Fully responsive using Tailwind CSS
